# 🚀 HTML Practice & Web Development Journey

Welcome to my repository! This project contains my hands-on practice, code files, and mini-projects while learning **HTML** and foundational **Web Development**.

---

## 📂 Project Structure

* **`index.html`** - My primary home page featuring navigation, descriptions, tables, forms, lists, and formatted text.
* **`About.html`** - An about page containing my introduction, images, and cross-navigation.
* **`HTML-Basics/`** - Contains fundamental tags, elements, and syntax practice.
* **`Classroom-prep/`** & **`intro-to-web/`** - Extra practice sessions and learning modules.

---

## 🛠️ What I Have Learned & Implemented

* **Basic HTML Tags & Structure** (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
* **Text Formatting & Styling:**
  * Bold, Italic, Underline (`<strong>`, `<em>`, `<i>`, `<u>`)
  * Highlight (`<mark>`)
  * Strikethrough & Insert (`<del>`, `<ins>`)
  * Subscript & Superscript (`<sub>`, `<sup>`)
* **Lists:**
  * Unordered Lists (`<ul>`)
  * Ordered Lists with Roman Numerals (`<ol type="I">`)
  * Nested Lists (Frontend, Backend, Database categories)
  * Description Lists (`<dl>`, `<dt>`, `<dd>`)
* **Tables:** Using rows, columns, borders, and `colspan`/`rowspan` properties.
* **Media:** Adding and styling images (`<img>`) with alternate texts.
* **Navigation & Links:** Multi-page linking between Home and About Us pages using anchor tags (`<a>`).
* **Basic Forms:** Input fields for user data and submission.
